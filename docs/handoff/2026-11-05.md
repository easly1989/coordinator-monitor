## What this session learned

- The test harness refuses an `on(...)` registered after the first `$` call: register hooks (`watch`, `track`) at the top of the test, then seed state.
- To prove a test is red: copy the changed file aside, `git checkout` it, run `claude plugin test .`, copy it back.
- `tsc` needs a tsconfig outside the repo (see the 2026-11-04 handoff) with the engine's `claude-code.d.ts` in `include`; the d.ts comes from the plugin-authoring skill's `types/` folder, whose path changes with each engine build.
- Hidden-character scan: pipe `git diff` into a small Python script that decodes UTF-8 and prints the `Cf`, `Zl`, `Zp` and U+00A0 characters.
- Messages from the coordinator rotate: the current id is in the latest cross-session message. Reports are short.
- `sync_with_base_branch` merges `main` into the branch; resolve the conflicts and `git commit --no-edit`.
